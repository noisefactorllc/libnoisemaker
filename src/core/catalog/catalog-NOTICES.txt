Notices for the effect catalog that libnoisemaker embeds

libnoisemaker embeds the effect catalog of the Noisemaker release that
share/noisemaker/ENGINE names. The shaders of that catalog contain code from
the works below. Each entry names a work and its source. Then it gives the
copyright notice and permission notice that the work's license requires,
copied from the license file that the entry names. For a work with no license
file, the entry names the Noisemaker source lines that state its license.
tools/catalog/check_notices.py checks that each license notice in the built
catalog belongs to an entry.
